# UniScope - Universal Serial Debugging Hub

UniScope 是一个功能强大的跨平台串口调试工具，提供可视化仪表板、实时数据绘图和协议分析功能。

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用
```bash
python main.py
```

## 功能特性

- 🎨 可拖拽仪表板
- 📊 7 种 Widget (示波器、终端、HEX查看器、仪表盘、数据表、协议分析器、图表)
- 🔌 I0-I14 多通道数据绑定
- 🌓 Dark/Light 主题切换
- 💾 JSON 布局保存/加载
